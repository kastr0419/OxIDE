# RP2040 (Raspberry Pi Pico) クレート使用ガイド

## 対応ボード一覧
| ボード名 | チップ | クレート |
|---|---:|---|
| Raspberry Pi Pico | RP2040 | rp-pico = "0.9" (BSP + hal) |
| Raspberry Pi Pico 2 | RP2350 | rp235x-hal = "0.2" |

## Cargo.toml 設定
以下は完全な Cargo.toml の例です（Raspberry Pi Pico, rp-pico）。

```toml
[package]
name = "blink"
version = "0.1.0"
edition = "2021"

[[bin]]
name = "blink"
test = false
bench = false

[dependencies]
rp-pico = "0.9"
cortex-m = { version = "0.7", features = ["critical-section-single-core"] }
cortex-m-rt = "0.7"
embedded-hal = "1.0"
panic-halt = "0.2"

[profile.release]
lto = true
opt-level = "s"
```

rp235x (Pico 2) 向けの例:

name = "blink"

## ツールチェーン設定
rust-toolchain.toml（例）:

```toml
[toolchain]
channel = "stable"
targets = ["thumbv6m-none-eabi"]
```

.cargo/config.toml（ビルドターゲットと runner）:

```toml
[build]
target = "thumbv6m-none-eabi"

[target.thumbv6m-none-eabi]
runner = "probe-rs run --chip RP2040"
rustflags = [
  "-C", "link-arg=-Tlink.x",
  "-C", "link-arg=--nmagic",
]
```

(注) Pico 2 / RP2350 の場合は target が異なる場合があります。BSP の README を参照してください。

## GPIO ピン初期化
以下は rp-pico BSP を使った典型的な初期化パターンです。

```rust
use rp_pico as bsp; // or use rp235x_hal as bsp for Pico 2
use bsp::hal::{clocks::init_clocks_and_plls, pac, sio::Sio, watchdog::Watchdog};
use cortex_m_rt::entry;
use panic_halt as _;

#[entry]
fn main() -> ! {
    let mut pac = pac::Peripherals::take().unwrap();
    let core = pac::CorePeripherals::take().unwrap();
    let mut watchdog = Watchdog::new(pac.WATCHDOG);
    let sio = Sio::new(pac.SIO);

    let clocks = init_clocks_and_plls(
        bsp::XOSC_CRYSTAL_FREQ,
        pac.XOSC, pac.CLOCKS, pac.PLL_SYS, pac.PLL_USB,
        &mut pac.RESETS, &mut watchdog,
    ).ok().unwrap();

    let pins = bsp::Pins::new(
        pac.IO_BANK0, pac.PADS_BANK0, sio.gpio_bank0, &mut pac.RESETS,
    );

    // Output 例: push-pull
    let mut out = pins.gpio15.into_push_pull_output();

    // Input 例: floating / pull-up による設定
    let input = pins.gpio14.into_floating_input();

    loop {}
}
```

## LED 制御
オンボード LED は通常 GPIO25 に割り当てられています（rp-pico の "led" alias を利用できます）。

```rust
// pins.led を使った Blink（rp-pico テンプレート）
let mut led = pins.led.into_push_pull_output();
loop {
    led.set_high().unwrap();
    delay.delay_ms(500);
    led.set_low().unwrap();
    delay.delay_ms(500);
}
```

## PWM 設定
rp2040 の PWM は PWM スライス/チャネル単位で扱います。以下は概略的な例です。

```rust
use bsp::hal::pwm::Slices;
use bsp::hal::gpio::FunctionPwm;

let mut pwm_slices = bsp::hal::pwm::Slices::new(pac.PWM, &mut pac.RESETS);
let mut pwm0 = pwm_slices.pwm0; // slice 0

// 出力ピンを PWM 機能に設定
let pwm_pin = pins.gpio0.into_mode::<FunctionPwm>();
// チャネル A をピンにマップ
pwm0.channel_a.output_to(pwm_pin);

// トップ値 (周期分解能) を設定
pwm0.set_top(65535);
// デューティを設定 (0..=top)
pwm0.channel_a.set_duty(32768);
// 有効化
pwm0.enable();
```

（注）API は hal のバージョンに依存します。詳しくは rp2040-hal のドキュメント参照。

## UART / シリアル通信
rp-pico BSP の UART 初期化例（UART0, gpio0/gpio1 を TX/RX に割当）:

```rust
use bsp::hal::uart::{DataBits, StopBits, UartConfig, UartPeripheral};

let uart_pins = (pins.gpio0.into_function(), pins.gpio1.into_function());
let mut uart = UartPeripheral::new(pac.UART0, uart_pins, &mut pac.RESETS)
    .enable(
        UartConfig::new(115200.Hz(), DataBits::Eight, None, StopBits::One),
        clocks.peripheral_clock.freq(),
    )
    .unwrap();

// ブロッキング書き込み
uart.write_full_blocking(b"Hello Pico!\r\n");

// 読み取り（nb::block! を使う）
// let byte = nb::block!(uart.read()).unwrap();
```

## タイマー / 遅延
cortex_m::delay::Delay を用いたミリ秒遅延の作り方（典型）:

```rust
let mut delay = cortex_m::delay::Delay::new(core.SYST, clocks.system_clock.freq().to_Hz());
delay.delay_ms(500u32);
```

## SPI / I2C（基本）
I2C0 の初期化（rp-pico スニペット）:

```rust
use bsp::hal::i2c::I2C;
let i2c = I2C::i2c0(
    pac.I2C0,
    pins.gpio4.into_function(), // SDA
    pins.gpio5.into_function(), // SCL
    400.kHz(),
    &mut pac.RESETS,
    &clocks.system_clock,
);
```

SPI の簡単な初期化（概略）:

```rust
use bsp::hal::spi::Spi;
use embedded_hal::spi::MODE_0;

let spi = Spi::new(pac.SPI0);
// SPI の初期化 API は hal のバージョンに依存します。
// 代表的にはクロック・モード・ピンを渡して init します。
```

## 注意事項・Tips
- memory.x と build.rs の設定
  - rp-pico BSP は多くの場合内部でリンクスクリプトを提供しますが、カスタム配置が必要な場合は memory.x を用意し、.cargo/config の rustflags で -Tlink.x を渡します。
- build.rs は外部ファイル埋め込みや生成をする場合に使います。BSP が提供する場合は不要。
- WS2812（NeoPixel）等の応用
  - 高精度タイミングを要する WS2812 は PIO（Programmable IO）で駆動します。rp2040-hal に PIO サポートがあり、ws2812 など専用クレートと組み合わせて使います。

## 割り込み
RP2040 では NVIC と PIO/Timer 割り込みを利用できます。PIO を使う場合は割り込みでデータの受け渡しを行うことが可能です。割り込みハンドラは短く保ち、共有リソースは適切に同期してください。

## よくあるエラーと対処法
- リンクエラー: リンカスクリプト (link.x / memory.x) が BSP の期待と合っているか確認してください。
- PIO が動作しない: PIO プログラムのタイミングやピン設定を確認し、BSP の例に従って初期化してください。
