# SVD ビューアの使い方

## SVD ファイルとは
SVD (System View Description) ファイルは、ARM Cortex-M 系マイコンの周辺機能（ペリフェラル）やレジスタ、ビットフィールドを定義した XML 形式のファイルです。レジスタのオフセットやフィールド名・ビット幅が記載されています。

## SVD ファイルの入手方法
- マイコンメーカーの公式サイト（ST, Nordic, Microchip など）
- CMSIS-Pack の pack-index（メーカーの Device Support パッケージ）
- 開発ボードの SDK に同梱されている場合があります

## 使い方
1. SVD ビューアで「Load SVD...」ボタンを押します。
2. .svd ファイルを選択します。
3. 読み込むと左側に周辺機能（Peripheral）のツリー表示が現れます。

## ツリー表示の見方
- Peripheral → Register → Field の階層で表示されます。
- レジスタ名をクリックすると、詳細（アドレスオフセット、アクセス権、説明）が表示されます。
- レジスタ名をクリックするとクリップボードにレジスタ名がコピーされる機能があります（該当する場合）。

## 検索
- 画面上部の検索ボックスに周辺機能名やレジスタ名を入力して絞り込めます。

## よく使う SVD ファイルの例
- STM32F4 系: ST 公式サイトのデバイスパック
- nRF52833 など: Nordic の公式ダウンロードページ

SVD を読み込むことで、デバッグ時にレジスタの意味をすばやく確認でき、クイック検索やコピーで開発効率が向上します。
