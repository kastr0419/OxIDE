# シリアルプロッタの使い方

シリアルプロッタはシリアル経由で送られてくる数値データをグラフ表示します。送信フォーマットに合わせてプロットされます。

## マイコン側のデータ送信形式
- name:value 形式（例: `temp:25.3\n`） → name をチャネル名として扱います。
- CSV 形式（例: `25.3,1.2,0.8\n`） → ch0, ch1, ch2 として扱われます。
- 複数チャンネル混在（例: `x:1.0,y:2.0,z:3.0\n`） → 各ペアが個別チャネルになります。

## 操作
- Pause / Resume: グラフ表示を一時停止・再開します。
- Clear: 内部バッファをリセットしてグラフをクリアします。
- Max Points スライダー: 画面に表示する最大点数を調整します（古い点は順次削除されます）。

プロッタを使うとセンサ値や制御ループの振る舞いをリアルタイムに確認できます。送信フォーマットに合わせてマイコン側の出力を調整してください。
