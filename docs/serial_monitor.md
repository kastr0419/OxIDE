# シリアルモニタの使い方

## 接続
1. 右パネルの Serial タブを選択します。
2. COMポートをドロップダウンから選択します。
3. Baud Rate（通信速度）を選択します。
4. 「Connect」ボタンを押して接続します。

## 受信ログの見方
- 受信データはタイムスタンプ付きでログパネルに表示されます。
- 長いログはスクロールして確認してください。

## 送信
- 送信ボックスにテキストを入力し、Enter キーまたは「Send」ボタンで送信します。
- 改行コード（\n）を加えるか、設定で自動改行を有効にしてください。

## Clear
- 「Clear」ボタンで受信ログをクリアできます。

## タブ切替
- Serial タブ内に「Monitor」と「Plotter」のタブがある場合、データ表示モードを切り替えられます。Plotter は数値データの可視化に使用します。
