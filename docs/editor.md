# エディタ機能

## ファイル保存
- 保存: Ctrl+S

## タブ操作
- 複数ファイルをタブで開けます。タブをクリックして切り替えます。

## インデント
- Tab キーでインデント（4スペース）を挿入します。
- Enter キーで自動インデントが行われます。

## ブラケット自動補完
- `{` を入力すると自動的に `}` が補完されます。

## ブラケットペアハイライト
- カーソル近くの対応する括弧・ブラケットがシアン色でハイライトされます。

## 補完候補
- 補完候補は rust-analyzer が必要です。
- Tab キーで候補を表示、↑↓ キーで選択、Enter で確定します。

## ブレークポイント
- エディタの行番号の左（ガター）をクリックするとブレークポイントがトグルされます（赤い●）。
