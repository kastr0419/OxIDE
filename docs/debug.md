# Debug パネルの使い方

このドキュメントでは Debug パネルの基本的な使い方を説明します。

## 対応ボード
- 対応: micro:bit, STM32F4
- 非対応: AVR（Arduino 系）, ESP32

## 接続手順
1. 左側の Board Picker で対象のボードを選択します。
2. COMポート（シリアルポート）を選択します。
3. Debug パネル内の「Connect」ボタンを押して接続します。

## 実行制御（Halt / Continue / Step）
- Halt: 実行中のプログラムを停止して CPU を停止状態にします。レジスタやメモリを確認できます。
- Continue: 停止中のプログラムを再開します。
- Step: 次の命令を1命令ずつ実行します（ステップ実行）。

## レジスタ一覧の見方
- パネルには主要レジスタが一覧表示されます: R0 - R12, SP（スタックポインタ）, LR（リンクレジスタ）, PC（プログラムカウンタ）, xPSR
- 値は通常16進で表示されます。レジスタ名をクリックするとクリップボードにコピーされる場合があります。

## メモリウォッチ
1. メモリウォッチ欄にアドレスを入力します（例: `0x20000000`）。
2. 「Watch」ボタンを押すと、そのアドレスの内容が16進で表示されます。
3. メモリの範囲読み取りやバイト/ワード単位の表示切替が可能な場合があります。

## ブレークポイント
- エディタのガター（行番号の左）をクリックすると赤い●のトグルでブレークポイントを追加／削除できます。
- Debug パネル内にもブレークポイントの一覧が表示され、そこから有効化／無効化や削除ができます。

## トラブルシューティング
- Windows 環境ではターゲットボードのUSBドライバとして WinUSB が必要な場合があります。
- Zadig（https://zadig.akeo.ie/）を使って適切なドライバ（WinUSB）に置き換えてください。
- デバイスが認識されない場合はケーブル、電源、ボードのブートモードを確認してください。
