# OxIDE — Rust製の組み込み向けGUI IDE紹介（使い方ガイド）

## はじめに
Rustで組み込み開発をする際、エディタやフラッシュのワークフローが分断されていることに不便を感じ、本プロジェクト「OxIDE」を作りました。Arduino IDEのようなワンストップな体験を、RustとモダンなGUI（egui/eframe）で実現することが目的です。

## OxIDEとは
OxIDEはデスクトップ向けのGUI IDEで、Arduino、Raspberry Pi Pico、ESP32、STM32F4などのボードをサポートします。ソースエディタ、ビルド＆フラッシュ、シリアルモニター、ピンアウトビューア、プロジェクトテンプレート生成、LSP連携（rust-analyzer）など、開発に必要な機能を一つのアプリで提供します。

## 主な機能
- ソースコードエディタ（シンタックスハイライト）
- ワンクリックでビルド＆フラッシュ
- シリアルモニター（接続／切断／送受信）
- ピンアウトビューア（複数ボード対応）
- プロジェクトテンプレート自動生成（27ボード対応）
- LSP連携（rust-analyzer）による補完・型チェック
- スタックアナライザーによる簡易トレース表示

## 対応ボード（概要）
- Tier 1（ビルド＋フラッシュ完全対応）: Arduino Uno, Arduino Nano, Raspberry Pi Pico, ESP32, STM32F4, nRF52840
- Tier 2（テンプレートのみ）: 27ボード対応
- Tier 3（ピンアウト表示）: Arduino Uno, ESP32, micro:bit V2, STM32F4

## インストール・セットアップ（Windows / Linux）
1. GitHubからリリースをダウンロード（v0.1.0 初回リリース）。
   - リポジトリ: https://github.com/kastr0419/OxIDE
2. 実行ファイルを展開して起動（Windowsは.exe、Linuxはバイナリ）。
3. 必要に応じて各ボード用のフラッシャやツール（avrdude, esptool.py, probe-rsの環境）をインストールしてください。
4. Rustベースのビルドを行うために、Rustツールチェイン（stable と board によってはnightly）が必要です。

※ 初回起動時にワークスペースディレクトリやtoolchainパスを設定できます。

## 使い方（ビルド〜フラッシュの流れ）
1. プロジェクトを作成／開く（テンプレートから選択可）。
2. エディタでソースを編集。LSPによる補完・診断が働きます。
3. ボードとポートを選択（Board Picker）。
4. 「Build」ボタンでビルドを行い、ログはBuild Panelに表示されます。
5. ビルド成功後、「Flash」または「Build & Flash」をクリックすると書き込みが実行されます。
6. シリアルモニターを開けば、デバイスとの送受信ログを確認できます。

内部的にはビルドやフラッシュは別スレッドで実行され、UIスレッドはcrossbeam-channelで結果を受け取って反映します。これによりUIは応答性を保ちます。

## メモ（トラブルシューティング）
- Windowsで子プロセスが別コンソールを開く場合、OxIDEはCREATE_NO_WINDOWのフラグを使ってコンソールを抑制します。
- 一部ボードではRustのnightlyが必要な場合があります（AVRターゲットなど）。
